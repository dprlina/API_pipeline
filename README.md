# API-пайплайн: анализ отзывов на протеин через LLM

## Описание задачи
Скрипт читает отзывы о протеине из CSV-файла, отправляет их в LLM через OpenRouter API, получает анализ тональности (positive/negative/neutral) и темы отзыва, сохраняет результат в CSV.

## Используемые технологии
- Python 3.11
- OpenRouter API (бесплатные модели)
- OpenAI Python SDK 

## Инструкция по установке и запске

### 1. Клонировать репозиторий
```
git clone https://github.com/dprlina/API_pipeline.git
cd API_pipeline
```
### 2. Установить зависимости
```
pip install openai
```
### 3. Получить API-ключ
- Зарегистрироваться на openrouter.ai
- Перейти в Keys
- Создать ключ
### 4. Вставить ключ в код
В файле pipeline.py заменить:
```
OPENROUTER_API_KEY = "ваш_ключ_сюда"
```
### 5. Запустить скрипт
```
python pipeline.py
```

## Входные данные (reviews.csv)
```
review_text
Попробовала пока только 1 шоколадный. Мне понравился вкус...
Хороший протеин! Вкусный и размешивается без комочков...
Очень приторно. Зачем так сладко?
Не до конца растворяется...
```

```
review,analysis

```
